# @yadsh/dsh-test-kit

Testing utilities for DeepSeek Harness plugins.

## Features

- Mock DSH plugin context
- Temporary fixture helpers
- Common test assertions (extensible)

## Installation

```bash
npm install @yadsh/dsh-test-kit --save-dev
```

## Development

```bash
pnpm build
pnpm test
pnpm typecheck
```
