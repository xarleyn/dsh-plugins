# Decision tools — specification

## 1. Product contract

Create @yadsh/dsh-decision-tools as an independent host-only plugin. Agent-facing tools: dsh_decision_capabilities, dsh_decision_ask, dsh_decision_classify, dsh_decision_check, dsh_decision_score, dsh_decision_rank.
Support all verified System One question kinds: noul, exclusive choice, ordered score. Generic ask accepts mixed typed questions; convenience tools compile into the same contract. Ranking uses explicit candidate ids and a shared ordered rubric, preserving original candidates and order on ties.
Configure named backends with operator-owned URL, model, key environment variable and declared question kinds. No URL or key arguments for the model. No automatic fallback to hosted endpoints. Tools are independent of Jev Compaction.
All inputs bounded: state characters/tokens, full request token estimate, questions, labels and candidate count. Never silently truncate user input or auto-read the chat/files. Cancelable global concurrency gate with bounded wait queue; deadline includes queue time; bounded response body. Reject malformed/missing/extra answer ids, wrong kind, unknown labels, nonfinite probabilities/confidence/scores, incorrect distribution keys/sums and scores outside the ordinal scale. Do not recompute score from temperature-scaled probabilities.
Output includes provider/backend id, resolved model, latency, usage, source probability distributions and uncertainty. Confidence is backend-specific evidence, not a guarantee of correctness. Noul has an abstention band; choice and score use configurable confidence floors; rank annotates uncertain scores. Model sees actionable errors, no request content or secrets in logs.
Default CPU budgets: 2400 estimated state tokens, 2600 estimated full-request tokens, 9000 state chars, 45s wall deadline, concurrency 1, queue 8, at most 8 questions/16 labels. Cross-question interference is documented for local Jeff isolate=none; do not claim independence or calibration. Native choice/check/score and rank are opt-in scoring calls, never irreversible actions.
Definition of done: SPEC/README examples, generator scaffold and locale metadata, test configuration/validation/deadlines/queue cancellation/dispose/tools/ranking, full package check, package hygiene, tarball install/import, live Jeff smoke for all three question kinds and wrappers, role-grant deployment instructions. Preserve foreign QA Surface WIP; do not commit/push/release automatically.
