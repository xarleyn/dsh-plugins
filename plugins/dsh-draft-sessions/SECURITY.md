# Security policy

## Supported versions

Only the latest released version is supported while the project is in alpha.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing draft text, filesystem paths, tokens, or a working exploit.

Include the affected version, operating system, DeepSeek Harness version, impact, and the smallest safe reproduction you can provide. You should receive an acknowledgement within seven days.

## Sensitive data

Draft text may contain source code, paths, or operational instructions. The plugin stores it unencrypted under the local DSH home and does not claim protection from other processes running as the same operating-system user. Do not sync the storage directory through an untrusted service.
