# Extended provider product contract

Provide @yadsh/dsh-llm-provider-extended as a replacement for the stock pi-ai adapter instance, preserving its provider configuration, catalog, discovery, credentials/native login, model metadata, reasoning, attachments, replay, attribution, retry and cancellation behavior. The official DeepSeek adapter can coexist on different routes. Route collisions are errors; never remove another adapter automatically.

Port the MIT-licensed llm-pi-ai implementation from deepseek-ai/deepseek-harness revision 477b4f420553e8a52c2fbccc464d7561b239c443, paired with DSH 0.1.7-rc.2 and pi-ai 0.85.1. Record provenance and upstream notices. Preserve upstream configuration fields and runtime behavior.

Add provider and per-model generation defaults: temperature, topP, topK, minP, frequencyPenalty, presencePenalty, seed and stop. Explicit call temperature/stop override defaults; model defaults override provider defaults. Only supported protocol parameters are accepted; no silent dropping. Preserve zero values. Additional wire fields must never replace model, history, tools, credentials or attribution. Validate ranges and supported protocol at configuration and request boundaries. Sampling is captured with prepared calls and does not change in flight.

Add a classic browser configuration body in this plugin's own Plugins row. Provide provider CRUD, protocol/base URL/display name/credential reference, model capacities/modalities and generation defaults, with advanced JSON preserving every upstream field. Use revision-fenced ConfigForm mutations, status/writable controls, summary view and design tokens. Native Models settings remain the credential/native-login and discovery UI for chat routes.

Add systemone as a typed-decision protocol accepting an explicit JSON envelope {state, questions} in one user text message. Register configured model metadata with text input only. Reject tools, chat history, reasoning, images, sampling, stop and output caps before transport. Send model/state/questions to the configured /v1/systemone endpoint; validate question kinds noul/choice/score and corresponding answers, preserve probabilities/confidence/usage. Return the response as one JSON text block, usage before finish. Never synthesize arbitrary chat or tool calls. No implicit hosted endpoint or authentication fallback. Existing decision-tools remain independent.

Definition of done: source and license provenance, documentation and migration guidance, version plan/manifest, meaningful configuration/HTTP/cancellation/lifecycle/card regression tests, lint/typecheck/tests/build/client/package/tarball verification. Report live browser and paid-provider checks separately when unavailable. No automatic commit, push, deployment or publication.
